# Market Bloom Groove

می‌خواهم ساخت سایت واقعی «ترابار | TERRABAR» را بر اساس سند اصلی پروژه و طراحی تأییدشده قبلی آغاز کنم.

ترابار یک بازار آنلاین تخصصی برای معاملات عمده و خرده میوه و تره‌بار، ارتباط تأمین‌کنندگان، بارفروشان و خریداران است.

الزامات مهم پروژه:

سایت فارسی و کاملاً راست‌چین (RTL) باشد و طراحی آن برای موبایل و دسکتاپ واکنش‌گرا باشد.

معماری و قابلیت‌ها مطابق سند اصلی ترابار پیاده‌سازی شوند؛ از جمله چهار بخش خریداران خرده، عمده، ویژه و ویژه حرفه‌ای.

پایگاه داده اصلی پروژه، Supabase موجود ترابار است. پروژه Supabase جدید نساز و هیچ جدول یا داده‌ای را بدون تأیید من ایجاد، حذف یا تغییر نده.

قوانین نقش کاربران، دسترسی جغرافیایی، انتشار بار، قیمت و موجودی، سفارش‌ها و پنل مدیریت باید در سمت سرور و با کنترل‌های امنیتی مناسب اجرا شوند؛ مخفی‌کردن عناصر در رابط کاربری به‌تنهایی کافی نیست.

اتصال متا و واتساپ فعلاً خارج از محدوده کار است.

قبل از هر تغییر مهم در دیتابیس، تنظیمات امنیتی، ساختار پروژه یا انتشار سایت، ابتدا توضیح بده و تأیید صریح من را بگیر.

فعلاً هیچ کد یا تغییری اجرا نکن. ابتدا محیط پروژه را بررسی کن و گزارش بده:

آیا پروژه‌ای از قبل در این فضای کاری وجود دارد؟

چه طراحی، صفحات و کدهایی موجود است؟

آیا اتصال به Supabase از قبل تنظیم شده است؟

برای ادامه، چه اطلاعاتی کم است؟

سپس برنامه اجرایی مرحله‌به‌مرحله پیشنهاد بده تا پس از تأیید من، ساخت سایت را آغاز کنیم.
